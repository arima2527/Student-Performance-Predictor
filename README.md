## 📌 Project Overview
This project uses Machine Learning to predict student marks based on factors like study hours, attendance, and sleep duration. It demonstrates how data can be used to make meaningful predictions in the education domain.

---

## 🧠 Technologies Used
- Python
- Jupyter Notebook
- Pandas
- Scikit-learn
- Matplotlib

---

## 📊 Dataset
The dataset includes:
- Study Hours
- Attendance
- Sleep Hours
- Marks

---

## ⚙️ Algorithm Used
**Linear Regression**

This algorithm is used to predict continuous values by finding relationships between variables.

---

## 🚀 How It Works
1. Data is created and loaded using Pandas  
2. Data is split into training and testing sets  
3. Linear Regression model is trained  
4. Predictions are made based on input  

---

## 📈 Output
The model predicts marks based on given inputs and displays results. A graph is also plotted to visualize the relationship between study hours and marks.
